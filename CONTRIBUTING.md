# Contributing

This repo hosts personal Claude Code mods. Issues and suggestions are
welcome via GitHub Issues. Pull requests are considered but not guaranteed
to be merged — these mods are built primarily for the author's own
workflow. Tests and test fixtures are not included in this copy.

To propose a change:
1. Open an issue describing the problem or suggestion first.
2. If a PR follows, keep it scoped to one mod and explain what you tested.
